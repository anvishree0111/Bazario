# Bazario

Bazario is a multi-vendor e-commerce marketplace where multiple sellers can create their shops and sell products online. It allows customers to explore products from different sellers and shop in one place.

## Project Purpose

The purpose of Bazario is to build a centralized online marketplace that connects sellers and customers, simplifies product discovery and purchasing, and enables multiple sellers to manage and sell their products through a single platform.

## Features

- **Multi-Vendor Marketplace:** Multiple sellers can sell their products on a single platform.
- **Seller Management:** Sellers can register, log in, create shops, and manage their products.
- **Product Catalog:** Customers can browse products available from different sellers.
- **Shopping Cart:** Customers can add products from multiple shops to a single cart.
- **Order Management:** Customers can place orders, while sellers can manage orders for their own products.
- **User Authentication:** Separate access for customers and sellers.
- **Database-Driven Products:** Product information is stored and managed in a MySQL database.

## Tech Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL
